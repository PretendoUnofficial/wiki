====== 3DS Error-Code 022-5432 ======

When linking a PNID or when accessing Juxtaposition, this error code may sometimes appear. This error is easy to fix with the following steps though:

   - Open Nimbus and switch to Nintendo servers
   - Open Miiverse((Some people may recommend opening eShop instead for this step but Miiverse is generally faster.)) (you should get error code 022-2882 if you've linked a Nintendo Network ID in the past or 015-5015 if you haven't)
   - Open Nimbus and switch back to Pretendo servers
   - Open Miiverse on Pretendo to check whether it's working properly (you should get error code 015-5015 to confirm this, if you get 022-5432, follow steps 1-4 again)
   - To fix error code 015-5015 on Pretendo, link a PNID by going to System Settings > Nintendo Network ID settings when connected to Pretendo servers in Nimbus.
