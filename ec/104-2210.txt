====== Error code 104-2210 ======

Clear shared save data for the game you're experiencing issues in.

    - Open System Settings and go into Data Management
    - Select Copy/Move/Delete Data
    - Select the hard drive where the game is stored and select the game having issues
    - Click on Shared Save Data and delete it
    - Reopen the game having issues and online should work correctly
