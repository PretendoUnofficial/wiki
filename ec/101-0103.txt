====== Wii U Error-Code 101-0103 ======

Check you've typed in the PNID of the user you're trying to add correctly.

If that doesn't work, ask someone to send you a friend request and it should work normally. You can use the [[https://forum.pretendo.network/t/wii-u-pnid-exchange/2238/|Wii U PNID Exchange]] to get someone to send you a friend request if necessary.
