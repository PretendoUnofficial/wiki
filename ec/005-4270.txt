====== 3DS Error-Code 005-4270 ======
This error occurs when attempting to perform an action on Pretendo that requires eCommerce servers. The fix for this error depends on what you are trying to do.

===== Installing/updating a game, app, or DLC =====
To update or install games from the 3DS, you will need to switch back to Nintendo Network via Nimbus to access the eShop. For legal reasons, Pretendo cannot and will not re-distribute this content.
===== Deleting a Pretendo Network ID =====
/* TO DO: Move some steps into separate page? */
Pretendo Network ID deletion currently does not work on 3DS, due to it attempting to access non-existent ECommerce servers.

To unlink a PNID from a 3DS, see [[:unlink-pnid|Unlinking a PNID]].
If you wish to delete the entire account, the account can either be deleted through a Wii U, or through [[https://pretendo.network/account|the account settings page]] on the Pretendo website. Note that the username will become permanently unavailable upon deletion.

===== After deleting a Pretendo Network ID =====
If you have deleted a Pretendo Network ID, either through the website or a Wii U, you will need to manually [[:unlink-pnid|unlink it from the linked 3DS]].
