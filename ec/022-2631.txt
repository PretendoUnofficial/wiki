====== 3DS Error Code 022-2631 ======
This error code means the linked Pretendo Network ID was deleted. The PNID will need to be removed manually.

The console may prompt to go to Nintendo Network ID settings and remove the ID from there. This will not work, and you will receive error code 005-4270.
To unlink the PNID, see the instructions [[:unlink-pnid|here]].
