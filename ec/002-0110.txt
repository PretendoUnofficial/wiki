====== 3DS Error-Code 002-0110 ======

This game isn't supported on Pretendo Network at this time. Please check out the [[:game-support-status|Game Support Status page]] for a list of currently supported games.

If the game you're attempting to play is supposed to be supported and it's a tester-only game, make sure [[https://forum.pretendo.network/t/-/4955|you're a donator at the Super Mario tier or above]] and make sure your friend code is whitelisted (you can request to be whitelisted on the [[https://forum.pretendo.network/t/3ds-friend-code-whitelisting-for-testing-servers/6186/1|forum]]).

If it's not a tester-only game, make a support post on the forum with the title ID for the game that you're trying to play online for your region.
