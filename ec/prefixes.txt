====== Error Prefixes ======

Here is documentation of what error code prefix is for which module.

| 002-XXXX  | NASC                                    | Accounts (NASC)                                                                      |
| 003-XXXX  | AC - Auto Connection                    | Internet Connection                                                                  |
| 004-XXXX  | BOSS                                    | SpotPass                                                                             |
| 005-XXXX  | NIM - Nintendo Installation Management  | Title Installation                                                                   |
| 006-XXXX  | NEX - Network Extension                 | Matchmaking Servers                                                                  |
| 007-XXXX  | Tiger                                   | Nintendo eShop API                                                                   |
| 008-XXXX  | Parental Controls                       | Parental Controls                                                                    |
| 009-XXXX  | Unknown                                 | Nintendo eShop related                                                               |
| 011-XXXX  | Nintendo eShop website                  | Nintendo eShop (website)                                                             |
| 012-XXXX  | Spider                                  | Old 3DS Internet Browser                                                             |
| 014-XXXX  | Cardboard                               | System Transfer                                                                      |
| 015-XXXX  | OLV - Olive                             | Miiverse                                                                             |
| 018-XXXX  | PIA                                     | Peer to Peer (P2P)                                                                   |
| 022-XXXX  | ACT - Accounts                          | Accounts (Nintendo Network ID)                                                       |
| 026-XXXX  | Unknown                                 | DLC/eShop related                                                                    |
| 028-XXXX  | Unknown                                 | System transfer related                                                              |
| 030-XXXX  | Unknown                                 | DLC/eShop related                                                                    |
| 032-XXXX  | Skater                                  | New 3DS Internet Browser                                                             |

| 034-XXXX  | Unknown                                 | Unknown meaning. Possibly unused?                                                    |
