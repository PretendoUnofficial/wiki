====== 3DS Error-Code 002-0121 ======

No, you're not banned.

To fix this issue, make sure that the first two options in Luma3DS settings are enabled. These are ''Enable loading external firms and modules'' and ''Enable game patching''. Additionally, ensure the bottom text also says ''Booted from SD via B9S.'' If it says ''Booted from CTRNAND via B9S.'' you will need to [[https://3ds.hacks.guide/restoring-updating-cfw.html|re-add Luma3DS to your SD]].

You can access Luma3DS settings by long pressing ''SELECT'' when booting up your console. Make sure to save your changes before exiting.

You can check whether it's fixed by opening the Friends List application. 

If it's not fixed, reinstalling the Pretendo patches can help. The easiest way to do so is through universal-updater.

If the issue is still not fixed, or the same error code also occurs on Nintendo Network, your ''LocalFriendCodeSeed_B'' file is likely broken and will need to be fixed. You can find more information about repairing your LFCS on the [[ec:002-0150|002-0150 page]].
